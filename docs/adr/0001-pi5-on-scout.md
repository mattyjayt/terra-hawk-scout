# ADR-0001 — Raspberry Pi 5 on the Scout first
- **Status:** Accepted (2026-10-30)
- **Context:** Only one Pi 5. SLAM, Nav2, EKF and perception need Pi-5-class compute.
- **Decision:** The Pi 5 rides on the Scout until the demo, then moves to the tower arm; a Jetson Orin Nano / second Pi follows.
- **Consequences:** recorded in the related design docs; revisit if the constraint changes.
